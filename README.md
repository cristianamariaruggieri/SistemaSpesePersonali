## Requisiti per l'esecuzione
Per far funzionare correttamente l'applicativo è necessario:
* Avere installato Python 3.x
* Utilizzare la libreria standard sqlite3 (già inclusa nell'installazione di Python)

## Istruzioni per eseguire il programma
1. Scaricare o clonare il contenuto di questo repository.
2. Aprire il terminale (o prompt dei comandi) nella cartella del progetto.
3. Eseguire il comando esatto:
   python src/main.py

## Struttura del Repository
Come richiesto dalle specifiche, il progetto è così organizzato:
* /src: Contiene il codice sorgente Python (main.py).
* /sql: Contiene lo script SQL per la creazione del database (database.sql).
* /demo: Contiene il video dimostrativo del funzionamento (video_dimostrativo.mp4).
